# PPP 고객 지원

**PPP — P의, P에 의한, P를 위한 즉흥 생활 앱**

PPP를 이용해 주셔서 감사합니다. 사용 중 궁금한 점이나 문제가 있으면 아래 방법으로 문의해 주세요.

## 문의하기

· 이메일: **soo1020p@gmail.com**

· 보통 2영업일 안에 답변드립니다.

· 문의 시 기기 모델, iOS 버전, 앱 버전(설정 탭 하단)과 문제 상황을 함께 적어주시면 빠르게 도와드릴 수 있습니다.

## 주요 기능

· **핫플**: 현재 위치 주변의 맛집·카페·명소·박물관·공원·쇼핑 장소를 거리순/추천순으로 보여줍니다. 장소를 누르면 Apple 지도(또는 선택한 지도 앱)로 열립니다.

· **식사**: 무엇을 먹을지 슬롯 룰렛으로 정해주고, 근처 식당을 지도에서 찾아볼 수 있습니다.

· **취미만들기**: 간단한 질문에 답하면 어울리는 취미를 추천합니다.

· **충동억제**: 야식·술·충동 쇼핑 등 하고 싶은 충동을 고르면 현실을 알려주며 한 번 더 생각하게 돕습니다.

· **설정**: 핫플 검색 반경, 룰렛 항목 등을 바꿀 수 있습니다.

## 자주 묻는 질문

**Q. 주변 핫플이 나오지 않아요.**

설정 앱 → 개인정보 보호 및 보안 → 위치 서비스 → PPP에서 위치 접근을 "앱을 사용하는 동안"으로 허용해 주세요. 앱 설정 탭에서 검색 반경을 넓혀 보셔도 됩니다.

**Q. 장소를 누르면 다른 지도 앱이 열려요.**

기본은 Apple 지도입니다. 핫플 화면 오른쪽 위의 지도 아이콘을 눌러 Apple 지도, 구글 지도, 네이버 지도 중에서 고를 수 있습니다.

**Q. 즉흥 코스는 무엇인가요?**

화면 왼쪽 위 PPP 로고를 7번 연속으로 누르면 오늘의 즉흥 코스를 추천해 드립니다. 하루 3번까지 쓸 수 있고, 설정에서 횟수를 초기화할 수 있습니다.

**Q. 제 정보가 저장되거나 전송되나요?**

PPP는 회원가입이 없고 개인정보를 수집하지 않습니다. 자세한 내용은 개인정보 처리방침(https://soo1020p.github.io/ppp-support/PRIVACY.html)을 확인해 주세요.
