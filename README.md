## 주요 기능

· **핫플**: 현재 위치 주변의 맛집·카페·명소·공원 등을 거리순/평점순으로 보여줍니다. 장소를 누르면 Apple 지도(또는 선택한 지도 앱)로 열립니다.

· **식사**: 무엇을 먹을지 룰렛으로 정해줍니다.

· **취미만들기**: 새로운 취미를 추천합니다.

· **충동억제**: 충동구매 등을 한 번 더 생각해 보게 돕습니다.

· **설정**: 검색 반경, 알림, 룰렛 항목 등을 바꿀 수 있습니다.

## 자주 묻는 질문

**Q. 주변 핫플이 나오지 않아요.**

설정 앱 → 개인정보 보호 및 보안 → 위치 서비스 → PPP에서 위치 접근을 "앱을 사용하는 동안"으로 허용해 주세요. 앱 설정 탭에서 검색 반경을 넓혀 보셔도 됩니다.

**Q. 장소를 누르면 다른 지도 앱이 열려요.**

핫플 화면 오른쪽 위의 지도 아이콘을 눌러 Apple 지도, 구글 지도, 네이버 지도 중에서 고를 수 있습니다.

**Q. 제 정보가 저장되거나 전송되나요?**

PPP는 회원가입이 없고 개인정보를 수집하지 않습니다. 자세한 내용은 이 저장소의 PRIVACY.md(개인정보 처리방침)를 확인해 주세요.

**Q. 후원(커피)은 어떻게 처리되나요?**

설정 탭의 후원은 Apple 인앱 결제로 처리되며, 결제 정보는 개발자에게 전달되지 않습니다. 환불은 Apple(reportaproblem.apple.com)을 통해 요청하실 수 있습니다.
